What's actually in the box

Four stages, one goal: get root, decrypt the flag.

RECON

Scan & explore

Walk the filesystem with ls / cd / cat, then scan the network to find the target host.

CRACK

Brute-force the vault

crack /root/shadow.enc runs a live brute-force animation that locks in the passphrase character by character.

ESCALATE

Get root

Use the recovered passphrase with sudo su to unlock the protected /root directory.

SAFETY

Nothing persists

State lives only in memory — no storage, no backend. reboot, or just close the tab, and it's a clean machine again.
